# AX(AI 전환) 연구 동향 분석기

NTIS 과제 · KCI 논문 목록을 넣으면 **기준 파일(`rules.js`)대로 AI 전환 자료를 골라** 키워드가 어떻게 늘고 줄었는지 표 · 그래프로 보여 주는 웹 도구입니다.
신흥기술영향평가세미나 2인 1조 실습(팀 저장소)을 바탕으로 한 **jimin9109의 중간 과제 고도화** 판입니다.

- **배포 주소**: https://jimin9109.github.io/research-trend-analyzer/
- **고도화 비교 링크** (팀 실습 마지막 병합 이후 바꾼 것): https://github.com/jimin9109/research-trend-analyzer/compare/f9f58dd...jimin-b
- 서버 없음 · 도구 안 AI 없음 · 키 · 비용 없음

## 쓰는 법

1. 배포 주소를 엽니다.
2. **예시 불러오기**를 누르면 `data/ax-ntis-kci.csv`(NTIS 과제 428행 + KCI 논문 725건)를 읽어 바로 분석합니다.
3. 화면 보는 법
   - **상단 총 · 과제 · 논문 칸**: 과제나 논문을 누르면 그 자료만으로 모든 그래프 · 표를 다시 계산합니다 (다시 누르거나 '총'을 누르면 전체)
   - **주제로 보기 / 키워드로 보기**: 처음에는 12개 주제로 묶어 보여 주고, 버튼으로 낱낱의 키워드 보기로 바꿀 수 있습니다
   - **상위 주제(키워드)** 막대: 파랑 = 과제, 주황 = 논문 · 막대를 누르면 오른쪽 추이와 아래 자료 목록에 그 주제가 나옵니다
   - **추세 목록**: 연도마다 `건수 · 비중` · 판정 탭(상승 · 신규 · 하락 · 유지 · 판정 보류 · 한 번만 나옴) · 검색 · CSV / 마크다운 내보내기
   - **주제 밖 키워드**(주제로 볼 때) / **판정 보류**(키워드로 볼 때): 기준 파일을 보강할 후보
   - **과제 vs 논문**: 과제와 논문에서 비중 차이가 큰 키워드
   - **거르기 결과**: 남긴 이유 · 뺀 이유 · 뺀 자료 목록
   - **적용한 기준**: 지금 `rules.js`에 들어 있는 판정 기준
4. 내 자료로 해 보기
   - NTIS · KCI에서 내려받은 `.xls`를 엑셀에서 **CSV UTF-8**로 저장 (NTIS는 첫 시트 '검색결과')
   - `node tools/prepare-ax.js <NTIS.csv> <KCI.csv> data/내자료.csv` 로 합치기 (연구책임자 · 저자 · 사업자번호 등 개인 · 기관 식별 열은 옮기지 않음)
   - **파일 선택**으로 넣기 · CSV 첫 줄에 `year,title`은 꼭 있어야 합니다

## 바꾼 기준과 이유

출발점은 팀 실습 마지막 병합 `f9f58dd`입니다. 그때 저장소에는 **환자경험평가** 기획안, 예시 입력 18편과 기대 결과, 그리고 가짜 데이터로 시험하는 B 화면(`demo/b-demo.html` · 그래프 · 목록 · 내보내기)이 있었습니다. CSV를 읽어 키워드를 세고 판정하는 부분과 전체 화면(`index.html`), 기준 파일(`rules.js`)은 아직 없었고, 판정 기준은 기획안에만 적혀 있었습니다.

1. `e6ea611` 기획안대로 대시보드 완성 (CSV 읽기 · 키워드 집계 · 추세 판정 · 화면 연결, 환자경험평가 예시)

## 확인한 방법

- 거르기 결과를 도구 코드와 따로 만든 스크립트 두 가지로 계산해 같은지 대조 (기간 제한 전 과제 235 · 논문 119 → 2023년부터 과제 232 · 논문 119)
- 남긴 자료 · 뺀 자료 목록을 사람이 훑어봄 (전수 확인은 아님)
- 디지털 트윈 · AI 에이전트 · 피지컬 AI는 원래 키워드 칸을 직접 세어 비중 · 증가율을 대조
- 다른 입력: 빈 줄 · 연도 없는 줄 · 형식 오류 줄은 줄 번호와 이유를 알림 · 정리된 자료 CSV를 다시 넣어도 같은 결과
- 배포 주소에서 예시 불러오기까지 동작 확인

## 한계 — 이 기준이 놓치는 것

- 검색어 'AX'로 모은 자료라 **AX라는 말을 쓰지 않은 AI 전환 연구는 빠짐**
- 거르기 규칙은 낱말 패턴이라 잘못 남기거나 뺀 자료가 있을 수 있음 → 뺀 자료 목록을 화면에서 확인
- **이 도구는 실제 연구의 흐름보다 'AX라는 말이 퍼지는 흐름'을 보여 줄 수 있음**: 2025년까지는 논문(37)이 과제(20)보다 많았는데, 2026년에 과제가 208건으로 급증 · 그중 사업 이름에 AX가 들어간 과제는 29건이고 나머지는 일반 사업에서 계획서에 AX를 쓴 것 → 정부가 AX를 정책 · 공모 언어로 쓰면서 지원자들이 그 말을 따라 쓴 영향이 클 수 있음 · '인공지능 도입' 같은 다른 검색어로도 비교해 봐야 함
- KCI 논문은 경영 · 법 · 과학기술학 같은 사회과학 비중이 높고, AI 기술 연구는 국제 학술지 · 학회로 가는 경우가 많아 덜 잡힘
- 이전 구간이 62건뿐이라 비중이 몇 건만 달라져도 크게 움직임
- 계속과제를 해마다 세서 오래 이어진 과제의 키워드가 여러 번 세어짐
- 2026년은 10월까지 자료
- 키워드는 원문(NTIS 한글키워드 · KCI 저자키워드)을 동의어 · 불용어로 정리한 것 · 어떤 낱말을 묶고 뺄지가 결과를 바꾸는 가치판단
- 주제 묶음은 낱말 패턴으로 붙여서, 키워드 하나는 위에 있는 주제 하나에만 들어감 (예: '제조 데이터'는 제조 AX로) · 주제 이름과 묶는 범위도 제가 정한 것 · 주제 밖 키워드 661개는 화면에서 확인 가능
